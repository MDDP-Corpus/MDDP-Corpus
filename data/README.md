# Dataset Availability

The MDDP-Corpus dataset generated in this study is publicly available through Zenodo.

## Dataset Repository

Dataset DOI:

https://doi.org/10.5281/zenodo.21722806

The dataset contains standardized metadata records of **25,952 data papers** collected from multiple scientific disciplines.

The released dataset includes structured bibliographic information and classification labels used for data paper identification and analysis.

## Data Format

The dataset is provided in tabular format and contains standardized metadata fields, including:

- Journal Name;
- DOI;
- Article Title;
- Abstract;
- Pub_Year;
- Label.

## Data Access

The complete dataset can be accessed and downloaded from the Zenodo repository:

https://doi.org/10.5281/zenodo.21722806

Due to copyright restrictions, the original full-text publications used for corpus construction are not included in this repository.
